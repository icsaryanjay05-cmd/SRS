# Social Run Series Website — V3

A premium animated homepage concept for **Social Run Series (SRS)**.

## V3 improvements

- 1.05-second cinematic SRS logo intro
- Scroll progress indicator
- Animated route/path graphics
- Kinetic RUN • CONNECT • BELONG marquee
- Subtle cursor glow on desktop
- Magnetic CTA buttons
- Lightweight 3D card tilt
- Scroll-reveal animations
- Animated identity stats using factual/non-invented values
- Community / Run-Connect-Belong feature panels
- Improved Current Events and SRS 5@5 cards
- Photo-ready SRS gallery without fake club photographs
- People of SRS / member spotlight section
- Dedicated SRS 5@5 result feature
- Sticky mobile JOIN SRS button
- Reduced-motion accessibility support
- Responsive desktop, tablet, and mobile layouts
